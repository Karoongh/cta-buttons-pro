== Description ==

**CTA Buttons Pro** قوی‌ترین و زیباترین افزونه دکمه‌های تماس برای وردپرس فارسی است.

امکانات کلیدی:
- دکمه شناور حرفه‌ای با افکت شیشه‌ای (Glassmorphism)
- نوار تماس ثابت پایین صفحه (فقط موبایل – بسیار محبوب در ایران)
- شورت‌کد اختصاصی برای هر دکمه: `[cta_whatsapp]`, `[cta_phone]` و ...
- نمایش همه دکمه‌ها با یک شورت‌کد: `[cta_buttons_pro]`
- آپلود آیکون سفارشی برای هر کانال
- آمار کلیک دقیق + تاریخ آخرین کلیک + ریست امن
- پشتیبانی کامل از المنتور (ویجت اختصاصی)
- طراحی ۱۰۰٪ واکنش‌گرا و RTL
- امنیت بالا و بهینه‌سازی سرعت
- بدون نیاز به دانش کدنویسی

پشتیبانی از:
- تلفن
- واتساپ
- تلگرام
- ایمیل
- اینستاگرام
- لوکیشن (گوگل مپ)

== Installation ==

1. افزونه را از طریق پیشخوان وردپرس → افزونه‌ها → افزودن → آپلود افزونه نصب کنید
2. افزونه را فعال کنید
3. به منوی **CTA Buttons Pro** در پیشخوان بروید
4. اطلاعات تماس خود را وارد کنید
5. از شورت‌کدها در پست‌ها، صفحات یا المنتور استفاده کنید

شورت‌کدهای مهم:
`[cta_buttons_pro]` → نمایش همه دکمه‌ها
`[cta_whatsapp]` → فقط واتساپ
`[cta_phone label="تماس فوری"]` → تلفن با متن دلخواه

== Frequently Asked Questions ==

= آیا در موبایل نوار تماس پایین نمایش داده می‌شود؟ =
بله! فقط در موبایل و تبلت نمایش داده می‌شود و بسیار حرفه‌ای و جذاب است.

= آیا می‌توانم آیکون هر دکمه را تغییر دهم؟ =
بله! در تب «آیکون سفارشی» می‌توانید برای هر کانال آیکون دلخواه آپلود کنید.

= آیا آمار کلیک دقیق است؟ =
بله! با Ajax و بدون رفرش صفحه ثبت می‌شود.
