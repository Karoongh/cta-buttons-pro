# CTA Buttons Pro

**دکمه‌های تماس شناور و ثابت حرفه‌ای برای وردپرس**

افزونه حرفه‌ای دکمه‌های تماس با طراحی Glassmorphism، آمار کلیک دقیق، شورت‌کد اختصاصی، خروجی CSV و پشتیبانی کامل از المنتور.

## امکانات

- دکمه شناور حرفه‌ای با افکت شیشه‌ای (Glassmorphism)
- نوار تماس ثابت پایین صفحه (مخصوص موبایل)
- شورت‌کدهای اختصاصی: `[cta_whatsapp]`, `[cta_phone]`, `[cta_telegram]` و ...
- نمایش همه دکمه‌ها با یک شورت‌کد: `[cta_buttons_pro]`
- آپلود آیکون سفارشی برای هر کانال
- آمار کلیک دقیق + تاریخ آخرین کلیک + جزئیات پیشرفته (IP، صفحه منبع)
- خروجی CSV از جزئیات کلیک‌ها
- پشتیبانی کامل از المنتور (ویجت اختصاصی)
- طراحی ۱۰۰٪ واکنش‌گرا و RTL
- امنیت بالا و بهینه‌سازی سرعت

## کانال‌های پشتیبانی‌شده

- تلفن • واتساپ • تلگرام • ایمیل • اینستاگرام • لوکیشن (گوگل مپ)

## نصب

1. پوشه افزونه را در `wp-content/plugins/` آپلود کنید.
2. افزونه را از پیشخوان وردپرس فعال کنید.
3. به منوی **CTA Buttons Pro** بروید و اطلاعات تماس را وارد کنید.

## شورت‌کدها

| شورت‌کد | توضیح |
|---------|-------|
| `[cta_buttons_pro]` | نمایش همه دکمه‌ها |
| `[cta_phone]` | دکمه تلفن |
| `[cta_whatsapp]` | دکمه واتساپ |
| `[cta_telegram]` | دکمه تلگرام |
| `[cta_email]` | دکمه ایمیل |
| `[cta_instagram]` | دکمه اینستاگرام |
| `[cta_location]` | دکمه لوکیشن |
| `[cta_button channel="whatsapp" label="چت با ما"]` | دکمه سفارشی |
